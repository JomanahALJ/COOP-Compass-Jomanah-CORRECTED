# COOP Compass — Jomanah's assigned part

This folder contains Jomanah's assigned Login and Sign-up pages for the CPIS-358 assignment.

## Files
- `login.html`: Login form.
- `signup.html`: Student registration form.
- `css/style.css`: External stylesheet, general classes, borders, shadows, and z-index.
- `js/script.js`: Functions, events, loops, if/else validation, and form validation.

## How to run
1. Open the whole `COOP-Compass` project folder in Visual Studio Code.
2. Open `login.html` in a browser (or use the Live Server extension).
3. Test empty fields, invalid email, short password, invalid student ID, and mismatched passwords.
4. Coordinate with your teammate before merging these files into the shared repository.

## Integration notes
The navigation links expect these shared files in the project root:
- `index.html` (teammate's Home page)
- `about.html` (teammate's About Us page)

Do not overwrite your teammate's files. Merge her pages with these files and keep one shared `css/style.css` and `js/script.js`.

## Important limitation
This is a static front-end assignment. Login and registration validation run in the browser only. There is no database, real authentication, or secure account creation.
